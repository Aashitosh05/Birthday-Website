# Birthday Website 🎂

A simple and personalized birthday website created using HTML and CSS.

## 📝 Description
This project is a static birthday website designed to wish someone in a creative and visual way.  
It focuses on layout, text styling, and basic responsiveness.

## 🚀 Features
- Personalized birthday message
- Clean and simple UI
- Beginner-friendly design

## 🛠️ Technologies Used
- HTML5
- CSS3
